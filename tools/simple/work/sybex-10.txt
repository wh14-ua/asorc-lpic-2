### SYBEX-CH10-RQ01  [multiple_choice]  tema: Compartición de archivos
P: ¿En cuál de los siguientes directorios encontraría normalmente los archivos de registro de Samba? (Elija la mejor respuesta.)
   A. /etc/smb/
   B. /etc/samba/
  *C. /var/log/samba/
   D. /var/lib/samba/
   E. /etc/samba.d/
LIBRO: La opción C es correcta, porque el directorio /var/log/samba/ es donde normalmente se encuentran los archivos de registro de Samba. El directorio /etc/smb/ (opción A), el directorio /etc/samba/ (opción B) y el directorio /etc/samba.d/ (opción E) son todos incorrectos, porque son (o fueron) directorios para guardar archivos de configuración de Samba. La opción D también es incorrecta, porque el directorio /var/lib/samba/ se usa para guardar cosas como las bases de datos de usuarios de Samba, no archivos de registro.

  *A. smbd
  *B. cupsd
   C. winbind
  *D. nmbd
   E. cifsd
LIBRO: La opción A es correcta, porque es el demonio que se usa en un servidor Samba para implementar el protocolo SMB. La opción B tiene algo de truco, pero también es correcta: el demonio de CUPS, cupsd, puede usarse junto con el demonio del servidor Samba para ofrecer recursos compartidos de impresión. La opción D también es correcta, porque si hay sistemas Windows antiguos en la red y se necesitan servicios Samba, hay que usar NetBIOS sobre TCP mediante el demonio nmbd. La opción C también tiene truco, porque el nombre real del demonio Name Service Switch es winbindd y no winbind, así que la opción C es errónea. La opción E es un nombre de demonio inventado y, por tanto, es incorrecta.

LIBRO: La opción D es correcta, porque después de modificar el archivo de configuración principal de Samba lo siguiente es comprobar su sintaxis, y el comando testparm hace justamente eso. El comando smbstatus muestra las conexiones actuales del servidor Samba, pero no comprueba la sintaxis del archivo de configuración, así que la opción C es errónea. La opción E también es incorrecta, porque crear un directorio o configurar una cola de impresión para compartir no es el paso siguiente necesario.
