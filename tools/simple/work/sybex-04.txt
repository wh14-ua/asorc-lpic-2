### SYBEX-CH04-RQ02  [multiple_choice]  tema: Sistemas de archivos

  *A. /proc/filesystems
   B. /etc/mtab
   C. /proc/mounts
   D. /proc/swaps
   E. /proc/cpuinfo
LIBRO: El archivo /proc/filesystems, opción A, contiene una lista de todos los sistemas de archivos soportados por el sistema. Los archivos /etc/mtab y /proc/mounts muestran los sistemas de archivos montados en ese momento. ### SYBEX-CH04-RQ03  [multiple_choice]  tema: Sistemas de archivos
P: Suponiendo que tiene (o puede obtener) privilegios de superusuario para acoplar temporalmente un sistema de archivos formateado a la estructura de directorio virtual de Linux, ¿qué debería hacer? (Elija la mejor respuesta.)
   A. Ejecutar el comando mkfs sobre el sistema de archivos con privilegios de superusuario.
   B. Ejecutar la utilidad e2label sobre el sistema de archivos.
   C. Nada. El servicio AutoFS lo acoplará automáticamente.
   D. Añadir una entrada para este sistema de archivos en el archivo de configuración /etc/fstab.
  *E. Usar el comando mount con las opciones y parámetros adecuados.
LIBRO: El comando mount con las opciones y parámetros adecuados acoplará temporalmente el sistema de archivos a la estructura de directorio virtual de Linux. Por tanto, la opción E es la mejor respuesta. El comando mkfs sirve para el formateo de alto nivel y no para acoplar un sistema de archivos, así que la opción A es incorrecta. La opción B es mala respuesta porque, aunque con el comando e2label se puede averiguar la etiqueta de un sistema de archivos, que luego podría usarse en el comando mount, no acopla ningún sistema de archivos. La opción C también es mala respuesta, porque AutoFS tiene que configurarse antes de que acople automáticamente un archivo en red. El archivo /etc/fstab es para sistemas de archivos acoplados de forma persistente, así que si se añade una entrada ahí, no quedaría acoplado temporalmente. Por tanto, la opción D no es la mejor respuesta.

### SYBEX-CH04-RQ05  [multiple_choice]  tema: Sistemas de archivos

   C. lsof
  *D. sync
   E. dmesg
LIBRO: La opción D es correcta, porque el comando sync permite vaciar los búferes del sistema de archivos, lo que en la práctica fuerza a que el volcado de datos se produzca de inmediato. Por tanto, la opción E es incorrecta.
