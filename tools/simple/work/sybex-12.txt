### SYBEX-CH12-RQ01  [multiple_choice]  tema: Seguridad del sistema
P: ¿Cómo se llama una vulnerabilidad que permite a un atacante obtener acceso a un sistema?
  *A. Vector de ataque
   B. Puerto abierto
   C. Aplicación abierta
   D. Comunicación no segura
LIBRO: Un vector de ataque es cualquier vía que permite a un atacante obtener acceso a un sistema. Como una vulnerabilidad permite el acceso a un sistema, es un vector de ataque; por tanto, la opción A es correcta. Las otras tres opciones solo describen otros tipos de vulnerabilidades, así que las opciones B, C y D son incorrectas.

### SYBEX-CH12-RQ02  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué archivo contiene una lista de los puertos estándar de las aplicaciones?
   A. /etc/ssh/sshd_conf
   B. /etc/openvpn
  *C. /etc/services
   D. /proc/sys/net/ipv4
LIBRO: El archivo /etc/services contiene una correspondencia entre números de puerto y aplicaciones, así que la opción C es correcta. El archivo /etc/ssh/sshd_conf es la configuración del servidor OpenSSH, la carpeta /etc/openvpn contiene archivos de configuración de la aplicación OpenVPN y la carpeta /proc/sys/net/ipv4 contiene ajustes de la pila IPv4 del kernel, así que las opciones A, B y D son todas incorrectas.

### SYBEX-CH12-RQ03  [multiple_choice]  tema: Seguridad del sistema

### SYBEX-CH12-RQ04  [multiple_choice]  tema: Seguridad del sistema

   A. telnet
   B. iptables
   C. ssh
  *D. netstat
LIBRO: El comando netstat puede mostrar todos los puertos abiertos que están escuchando conexiones de red entrantes, así que la opción D es correcta. El comando telnet solo puede conectarse a un puerto cada vez, así que la opción A es incorrecta. El comando iptables trabaja con las funciones de procesamiento de paquetes del kernel y no con puertos de red, así que la opción B es incorrecta. El comando ssh solo puede conectarse al puerto 22, así que la opción C es incorrecta.

### SYBEX-CH12-RQ06  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué opción de nmap indica que debe determinar la huella (fingerprint) del sistema remoto?
  *A. -A
   B. -sT
   C. -sU
   D. -p
LIBRO: La opción –A indica a nmap que realice un análisis de huella del sistema remoto, así que la opción A es correcta. La opción –p indica un rango de puertos a escanear, así que la opción D también es incorrecta.

### SYBEX-CH12-RQ07  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué función de OpenVAS le permite simular distintos ataques de vulnerabilidad sobre el sistema que analiza?
   A. La National Vulnerability Database (NVD)
   B. El repositorio de software
  *C. Los Network Vulnerability Tests (NVT)
   D. La interfaz web
LIBRO: Los Network Vulnerability Tests (NVT) simulan ataques conocidos contra los sistemas y se descargan como parte de OpenVAS, así que la opción C es correcta. La National Vulnerability Database (NVD) la mantiene US-CERT para definir vulnerabilidades, pero no para simularlas, así que la opción A es incorrecta. El repositorio de software de la distribución no almacena vulnerabilidades, así que la opción B es incorrecta. La interfaz web permite interactuar con OpenVAS, pero no simula vulnerabilidades, así que la opción D es incorrecta.

### SYBEX-CH12-RQ08  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué tipo de software puede avisarle de un ataque activo contra su sistema?
   A. Escáner de puertos
   B. Network Vulnerability Test (NVT)
   C. Red privada virtual (VPN)
  *D. Sistema de detección de intrusiones (IDS)
LIBRO: Un sistema de detección de intrusiones (IDS) puede vigilar los eventos del sistema y de la red en busca de indicios de que se está produciendo un ataque activo, así que la opción D es correcta. Los escáneres de puertos pueden informar de vectores de ataque abiertos, pero no de cuándo se está produciendo un ataque, así que la opción A es incorrecta. El Network Vulnerability Test (NVT) simula ataques, pero no avisa de ataques en curso, así que la opción B es incorrecta. La VPN permite establecer una conexión segura entre dos hosts remotos, pero no avisa de un ataque, así que la opción C es incorrecta.

### SYBEX-CH12-RQ10  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué aplicación es un sistema de detección de intrusiones en red (NIDS)?
  *A. Snort
   B. OpenVPN
   C. OpenSSH
   D. OpenVAS
LIBRO: La aplicación Snort vigila la red en busca de ataques activos, así que la opción A es correcta. El paquete OpenVPN proporciona un túnel cifrado entre dos redes públicas para ofrecer un entorno seguro, pero no actúa como NIDS, así que la opción B es incorrecta. La aplicación OpenSSH proporciona un canal seguro entre un cliente y un servidor, pero no vigila los paquetes de la red, así que la opción C es incorrecta. La aplicación OpenVAS es una herramienta de vulnerabilidades, pero por sí sola no vigila los paquetes de la red, así que la opción D es incorrecta.

### SYBEX-CH12-RQ13  [multiple_choice]  tema: Seguridad del sistema

   B. 10.0.0.2 -> 10.0.0.1
   C. 10.0.0.1 <> 10.0.0.2

### SYBEX-CH12-RQ15  [multiple_choice]  tema: Seguridad del sistema
P: ¿Con qué valor empiezan las direcciones IPv6 de enlace local?
  *A. fe80
   B. ff02
   C. ff05
   D. aabb
LIBRO: El valor fe80 identifica la dirección inicial de las direcciones de enlace local en IPv6. El resto de la dirección suele derivarse de la dirección MAC Ethernet para garantizar que sea única en la red. El valor ff02 es la dirección de multidifusión para routers y ff05 es la dirección de multidifusión para servidores DHCP, así que la opción C es incorrecta. El valor aabb no es un número reservado en IPv6, así que la opción D es incorrecta.

   A. SSH

  *C. NAT

### SYBEX-CH12-RQ19  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué política de iptables se usa para devolver un paquete al origen indicando que el paquete fue descartado?
  *A. REJECT
   B. DROP
   C. ACCEPT
   D. LOG
LIBRO: La política REJECT descarta el paquete pero envía un mensaje ICMP de vuelta a la dirección IP de origen indicando el fallo; por tanto, la opción A es correcta. La política DROP descarta el paquete de forma silenciosa, así que la opción B es incorrecta. Las políticas ACCEPT y LOG aceptan todos los paquetes, y la política LOG además guarda información del paquete en un archivo de registro, así que las opciones C y D son incorrectas.

### SYBEX-CH12-RQ20  [multiple_choice]  tema: Seguridad del sistema
P: ¿Qué opción de iptables define la política predeterminada de una cadena?
  *A. -P
   B. -j
   C. -L
   D. -F
LIBRO: La opción –P define la cadena y la política que se usará por defecto. La opción –j define la acción de una regla, así que la opción B es incorrecta. La opción –L solo lista cadenas y tablas; no las modifica, así que la opción C es incorrecta. La opción –F elimina todas las reglas de la cadena, así que la opción D es incorrecta.
